# ListaFácil

**Organize seu dia, uma tarefa de cada vez.**

O ListaFácil é uma aplicação web desenvolvida para facilitar a organização da rotina por meio do cadastro, acompanhamento e gerenciamento de tarefas diárias.

## Sobre o projeto

O projeto foi desenvolvido com o objetivo de oferecer uma ferramenta simples e intuitiva para ajudar os usuários a organizar suas atividades, acompanhar tarefas pendentes e visualizar seu progresso.

## Funcionalidades

- [x] Adicionar novas tarefas.
- [x] Listar tarefas cadastradas.
- [x] Marcar tarefas como concluídas.
- [x] Excluir tarefas.
- [x] Filtrar tarefas por situação.
- [x] Salvar tarefas no navegador utilizando LocalStorage.
- [x] Exibir o resumo de tarefas totais, pendentes e concluídas.
- [x] Impedir o cadastro de tarefas vazias.

## Tecnologias utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização e responsividade.
- **JavaScript:** funcionalidades e interatividade.
- **LocalStorage:** armazenamento local das tarefas.
- **Git:** controle de versão.
- **GitHub:** hospedagem do código e gerenciamento de mudanças.

## Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Instale a extensão Live Server.
4. Abra o arquivo `index.html`.
5. Clique com o botão direito e selecione **Open with Live Server**.
6. O ListaFácil será aberto no navegador.

## Armazenamento dos dados

As tarefas são armazenadas no LocalStorage do navegador. Dessa forma, os dados permanecem salvos mesmo após atualizar ou fechar a página, desde que os dados do navegador não sejam apagados.

## Controle de versão

O projeto utiliza Git e GitHub para organizar o desenvolvimento e registrar as alterações realizadas.

O fluxo de trabalho inclui:

- Issues para registrar problemas e melhorias.
- Branches para desenvolver alterações separadamente.
- Commits para registrar mudanças no código.
- Pull Requests para solicitar revisões.
- Code Review para analisar as alterações.
- Merge para integrar mudanças à branch principal.

## Objetivo acadêmico

Este projeto foi desenvolvido como atividade prática de aprendizagem sobre controle de mudanças, versionamento de código e colaboração no desenvolvimento de software.
